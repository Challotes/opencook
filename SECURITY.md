# Security

OpenCook moves real money (BSV), so security reports are taken seriously and are very welcome.

## Reporting a vulnerability

**Please report privately — do not open a public issue or post it on the feed.**

Use GitHub's private reporting: go to this repo's **Security** tab and click **Report a vulnerability**. Only the maintainer can see your report.

Please include what you found, how to reproduce it, and what an attacker could do with it.

## What counts

Anything that could:

- move, redirect or drain funds (boost payments, payout splits, the server wallet)
- expose or misuse anyone's private key or recovery file
- let someone post, boost or claim credit as another person
- bypass rate limits, spending caps or the content filter
- leak secrets or private data

## What happens next

You'll get a reply as soon as possible. Please give a reasonable chance to fix the issue before sharing it publicly. Reporters are credited in the fix unless they'd rather stay anonymous.
